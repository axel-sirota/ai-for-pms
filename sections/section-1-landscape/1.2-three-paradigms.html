1.2 The Three Paradigms

Classical ML vs LLMs vs Agents — the core framework for every AI decision

This Is the Most Important Framework in the Course

Every AI product decision starts here. When someone says "let's add AI to the product," your first question should be: which paradigm fits this problem? Getting this wrong wastes months and millions.

The Three Paradigms at a Glance

Classical ML LLMs Agents
Best For Prediction from structured data Text understanding & generation Multi-step autonomous tasks
Data Needs Thousands of labeled examples Examples in the prompt Task definitions + tools
Timeline to POC 2–4 months Days to weeks Weeks to months
Timeline to Production 6–9 months 2–3 months 4–6 months
Explainability High (feature importance) Low to Medium Medium (reasoning trace)
Cost Profile High upfront, low ongoing Low upfront, per-query ongoing Medium upfront, higher per-task
Examples Churn prediction, fraud detection, demand forecasting Customer support, content generation, summarization Research assistant, booking agent, expense processing

When Each Paradigm Wins

Classical ML Wins When...

  • You have structured, tabular data
  • You need to predict a number or category
  • Explainability is required (regulated industries)
  • You have historical data to learn from
  • Low-latency inference matters

Think: "Will this customer churn?" "Is this transaction fraud?"

LLMs Win When...

  • The task involves understanding or generating text
  • You need flexibility across many tasks
  • You can't define rules in advance
  • Speed to market matters most
  • You don't have training data

Think: "Summarize these tickets." "Draft a response to this complaint."

Agents Win When...

  • The task requires multiple steps in sequence
  • The system needs to use external tools (APIs, databases)
  • Decisions depend on intermediate results
  • You'd otherwise need a human to coordinate
  • You can tolerate higher latency per task

Think: "Research competitors and compile a report." "Process this expense claim end-to-end."

Common Paradigm Mistakes

Mistake Example What Should Have Happened
Using LLM when ML is better LLM to predict churn from structured CRM data Classical ML — faster, cheaper, more accurate on tabular data
Using ML when LLM is better Training a classifier for 200 categories of support tickets LLM with few-shot prompting — no training data needed
Jumping to agents too early Autonomous refund agent before testing a copilot version Start with copilot (suggestions), earn trust, then automate
Using AI when rules suffice ML model to route tickets based on simple keyword matching If-then rules — simpler, faster, 100% predictable

Stakeholder Framing

When your VP asks "Why can't we just use ChatGPT for everything?", here's your answer:

"AI isn't one thing — it's three different approaches, each with different strengths. Using ChatGPT for everything is like using a hammer for every home repair. We need to match the tool to the job: structured predictions use traditional ML, text tasks use LLMs, and complex workflows use agents. Getting this match right is the #1 predictor of AI project success."
