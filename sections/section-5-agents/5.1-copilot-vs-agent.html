SECTION 5.1

Copilot vs Agent

When AI Should Suggest vs When It Should Act

The Autonomy Trap

2023 Airline Booking Bot: An autonomous booking agent was given permission to "find the best deals." It booked 47 non-refundable tickets for one customer because it interpreted "best deals" as "all deals under $200." Cost: $8,400 and a viral complaint thread.

The Core Distinction

Dimension Copilot Agent
Autonomy Suggests, human decides Decides and acts
Risk Low (human in loop) Higher (autonomous actions)
Trust Required Low High
Speed Slower (human review) Faster (no waiting)
Example GitHub Copilot, email suggestions Booking agent, automated trading

PM Decision Point

Before launching any AI feature, ask: "What's the blast radius if this goes wrong?"

  • Small blast radius (typo in email draft) = Copilot fine
  • Medium blast radius (wrong meeting scheduled) = Agent with undo
  • Large blast radius (money transferred, data deleted) = Require approval

Real-World Examples

Copilot Examples

  • GitHub Copilot (suggests code)
  • Gmail Smart Compose (suggests text)
  • Notion AI (suggests edits)
  • Grammarly (suggests corrections)

Pattern: User reviews before action

Agent Examples

  • Klarna customer service (resolves issues)
  • Trading algorithms (executes trades)
  • Email auto-responders (sends replies)
  • Smart home systems (adjusts settings)

Pattern: Acts without waiting for approval

The Reversibility Test

Action Reversible? Recommendation
Draft an email Yes (don't send) Copilot
Send an email No Agent + Approval
Schedule a meeting Yes (can cancel) Agent OK
Make a purchase Sometimes Agent + Threshold
Delete data No Always approve
Transfer money No Always approve

PM Insight

Start as a copilot, graduate to an agent. Even Klarna started with human review for every response. They earned agent status through 2 years of demonstrated reliability.

How to Explain This to Stakeholders

"A copilot is like a helpful assistant who drafts things for you to approve. An agent is like a trusted employee who can act on your behalf. We start with copilots and promote to agents only after the AI proves it can handle the responsibility."
