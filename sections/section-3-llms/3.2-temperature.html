Temperature

The creativity-consistency dial every PM needs to understand.

When Temperature Goes Wrong

A customer service bot set to temperature 1.0 told a customer their order would arrive "on the wings of a thousand doves, probably Tuesday or perhaps the heat death of the universe."

The customer filed a complaint. The PM had never heard of temperature settings.

Lesson: Temperature is a product decision, not just an engineering parameter.

What Is Temperature?

Temperature controls how "random" the model's word choices are. At every step, the model picks the next word from a probability distribution. Temperature changes that distribution:

Temperature Use-Case Matrix

Temperature Behavior Best For Avoid For
0 Deterministic - same output every time Factual Q&A, data extraction, classification, code generation Marketing copy, brainstorming
0.3–0.5 Slight variation, mostly consistent Customer support, summaries, translations Tasks requiring exact reproducibility
0.7–1.0 Creative, varied outputs each time Marketing copy, brainstorming, story writing Medical/legal/financial advice
>1.0 Very random, may produce nonsense Rarely useful - experimental only Almost everything in production
PM Rule of Thumb

Start at temperature 0 for production. Increase only if you have a specific reason.

Most product features (search, support, extraction, classification) work best at 0. Only increase for creative tasks like content generation.

Same Prompt, Different Temperatures

Prompt: "Write a one-sentence product description for noise-canceling headphones."

Temperature 0

"Experience crystal-clear audio with our premium noise-canceling headphones, designed to block out distractions and deliver immersive sound quality."

Run 3 times: identical output each time

Temperature 0.5

"Block the world out and tune into pure, uninterrupted sound with our advanced noise-canceling headphones."

Run 3 times: similar structure, slightly different words

Temperature 1.0

"Silence becomes your superpower — these headphones don't just cancel noise, they create your personal concert hall."

Run 3 times: noticeably different each time

Common PM Scenarios

Your Feature Recommended Temperature Why
Customer support chatbot 0 Consistency matters. Same question should get same answer.
Email subject line generator 0.7–0.9 You want variety. 10 different options to choose from.
Legal document summarizer 0 Accuracy over creativity. No room for "creative" legal interpretations.
Product review analyzer 0 Extraction task. "Is this positive or negative?" needs consistent answers.
Marketing blog post writer 0.8 Creative writing benefits from variety.
Code documentation generator 0 Technical accuracy. No creative license needed.

Stakeholder Framing

When engineering says "we set temperature to 0.9 for better results":

"What problem are we solving with higher temperature? For our support chatbot, consistency is more important than creativity. A customer asking about returns should get the same answer every time. Let's set it to 0 and only increase if we see the responses are too rigid for a specific use case."
